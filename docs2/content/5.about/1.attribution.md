Firefly Pico was developed by Mihai Cioraneanu as a companion interface for Firefly III. The repository is licensed under the GNU Affero General Public License v3; read the root `LICENSE` file when adapting or distributing the project.

The app builds on Firefly III's API, Laravel, Nuxt, Vue, Pinia, and Vant, with Tabler icons and other dependencies listed in the package manifests. Its currency integration uses Exchange Rate API.

This developer guide uses Docus for its documentation layout and navigation. The diagrams in this guide describe Pico's own structure and are stored as editable SVG assets alongside the content.

Keep existing license and attribution notices when working on a fork. Consult each dependency's license for its own terms; the application license does not replace them.
